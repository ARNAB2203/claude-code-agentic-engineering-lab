## Practical-exercise pattern

Every lab must state its objective, prerequisites, executable steps, expected outcome, verification, common errors, assignment, interview questions, and best practices. Capabilities unavailable in the local installation must be labelled as walkthroughs with a verification prerequisite, never as executed demonstrations.
